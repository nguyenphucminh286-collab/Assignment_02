# Product Backlog

## US-101 - Login
As a student, I want to log in to the system,
so that I can access my account.

## US-102 - Course Management
As a student, I want to view available courses,
so that I can choose a course to study.

## US-103 - Quiz
As a student, I want to take quizzes,
so that I can test my knowledge.

## US-104 - Learning Progress
As a student, I want to view my learning progress,
so that I can monitor my study results.
